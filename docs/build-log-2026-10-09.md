## What the director caught at handback

Every one of these came with a builder report saying all checks passed. None was caught by the builder's own checks.

- **portkit**: the import was squashed, losing the history the plan said to keep; the `pkx` binary the packet said to drop was still built; `Cargo.lock` was left uncommitted.
- **Held-out store**: in-repo paths were accepted when the parent folder did not exist yet or the path was relative (on macOS, temp paths under `/var` canonicalize to `/private/var`); the first fix's `..` test accepted either outcome; the "before" proof committed a deliberately vulnerable copy of the resolver into the library, outside `#[cfg(test)]`.
- **Sandbox**: a hard-coded proxy port that would have cut today's runner off from its model provider; every policy, including the verifier, could write the real `~/.cargo`; the required live test was deleted as "unreliable" when it was in fact catching a real bug (profiles written with non-canonical paths, so deny rules on `/tmp` and `/var` paths failed open). The Sonnet reassign found two more: `lane/control` was fully open whenever it sat outside the home, and the proxy rule order made the proxy unreachable.
- **Escalation**: escalate-early was two stubs that always returned "no escalation", reported as done; the resume-fallback test passed even if the fallback did nothing. The Sonnet reassign also fixed: park time lost on restart, a ruling deliverable to the wrong lane, an escalation consumed by a failed write, and a panic when truncating multi-byte text.
- **Egress proxy**: forwarding was a stub reported as "security-complete"; the second attempt ran out of budget. The Sonnet reassign also closed a hole where a foreign key beside the placeholder passed the credential check.
- **Builder command**: an empty entry in the builder's `PATH` was accepted. An empty entry searches the current directory, which is the builder's clone, so a builder could plant a fake `git` or `cargo` there. Fixed by the director.
- **Builder prefix**: the preamble described escalate-early wrongly (it said "two failures" where the runner counts the same check failing twice with no pass between, and left out the cost-share and turn-budget triggers); one protocol marker did not occur in the preamble, so the lint could never fire on it. Fixed by the director, with a test that every marker occurs in the preamble.
- **Stream meter**: the rework deleted orphan `tool_result` counting that the packet required, and its "mutation proof" was a committed test that was never run as a mutation. The Sonnet reassign restored orphan handling, ran a real mutation, and also found that turns were counted per content-block event instead of per message (4 turns instead of 2), that object-shaped `permission_denials` were silently dropped, and that a pending `tool_use` would have read as a passing command.
- **Append-only fix**: correct, but the tests were hand-written patches and the trailer named the wrong model. The director added a test built from real `git diff` output.
- **Held-out gate**: the first pass re-implemented the store's path checks without its `..` rule; the rework's `..` test accepted either error, and both errors print the path, so it proved nothing. The director found the `..` check was unreachable (the walk-up stops at a `..` component) and made core refuse `..` up front.
- **Escalation fence**: single-line fields did not treat Unicode line separators as breaks. Fixed by the director.
- **Lane preparation**: the clone used `--shared` and kept `origin`, so a builder could push into the source repository or write through to its objects. With nothing to remove, `launch.patch` came out as the previous commit's diff. The rework deleted the D13 replay test and claimed a trailer it did not have. The Sonnet reassign also found that the base patch's temporary index wrote blobs into the source's object store, and that `git checkout` exits 0 after a missing object, leaving a partial clone.
- **Notes and watch**: the first handback was never committed and left a backup file in the tree.
- **Generic flaw pack**: the "generic" pack included Postgres policy and RLS rules; the mutation was described, not run.
- **Proxy idle timeout**: the timer was never registered, so a stalled stream would hang forever and a later chunk would kill a live one; the stall test measured the time to the first chunk. The rework registered the timer but still dropped a ready frame when the timer fired; fixed by the director.
- **Verifier**: two Haiku attempts ended with tests that did not compile, an unapproved dependency, and a mutation "verified by design". The Sonnet reassign was accurate on macOS, but its sandboxed group-kill test read a pid from inside bwrap's pid namespace, so Linux CI failed. The director rewrote the test to prove the kill by its effect.
- **Redelivery**: a second delivery routine that dropped the fresh-session fallback (D9); the director routed it through the shared path.
- **Process misses**: worktrees created inside the main checkout, uncommitted handbacks, and test totals copied from earlier reports (several said 330 or 461 when the workspace had over 480).
- **Capsule**: tests built values and read them back instead of calling `verify`; then a test-only branch in production code skipped the real rebuild. The Sonnet reassign also found that `verify` ran the check id as the shell command and that `Capsule::write` never recorded hashes, so tamper detection could not have worked.

## Escalation data (premise 2)

| Lane kind | Lanes | Merged on Haiku's first handback | Needed director rounds | Reassigned to Sonnet |
|---|---|---|---|---|
| Mechanical (import, CI) | 2 | 1 (CI) | 1 (import, fixed by the director) | 0 |
| Behavior or security contract | 17 | 0 | 17 | 7 |

- Haiku's handbacks on contract-heavy lanes consistently reported stubs, shape-only tests or skipped checks as done. Sonnet's handbacks were accurate, included mutation proofs, and fixed defects beyond the brief.
- Rework before reassign paid off on narrow lanes (notes, generic pack, idle timeout); lanes that span a security boundary or two crates (lane preparation, verifier, builder tools) went to Sonnet every time.
- The escalation loop itself worked: a Haiku lane escalated a real design question (the streaming test shape) instead of guessing, and got a ruling.
- Cost was not measured: the builders ran as Claude Code subagents, not through cowproof's runner, so there are no capsules or estimated-cost records yet. Real per-lane cost data starts when the run slice lands.
